# Windows 11 备忘录悬浮助手完整方案

## 1. 产品目标

实现一个本地优先、低资源占用的 Windows 11 桌面备忘录工具。程序以可拖动悬浮球常驻桌面；点击后展示当天创建的记录；鼠标离开后自动收起；支持创建、编辑、完成、删除和定时提醒。

## 2. 目标用户与核心场景

- 用户工作时需要快速记下一项任务，不希望切换到大型笔记软件。
- 用户希望从桌面随时看到今天新增的事项。
- 用户希望某条事项在指定时间触发 Windows 通知。
- 用户希望所有内容仅保存在本机。

## 3. 功能范围

### 3.1 第一版功能

1. 58×58 DIP 无边框透明悬浮球，始终置顶。
2. 按系统拖动阈值区分单击和拖动。
3. 拖动结束吸附当前显示器最近的左右边缘。
4. 保存位置；显示器变化后自动恢复到可见工作区。
5. 点击后在悬浮球内侧展示面板。
6. 面板显示本地日期当天创建的记录，未完成项排在前面。
7. 面板离开 700ms 后收起；编辑对话框打开时不收起；`Esc` 立即收起。
8. 创建、编辑、完成/重新打开、永久删除记录。
9. 可为记录设置一个单次提醒时间。
10. 每 30 秒检查到期提醒，并通过系统托盘显示通知。
11. 启动后补发程序停止期间尚未发送的到期提醒。
12. 托盘常驻、单实例、开机启动开关及明确退出入口。
13. SQLite 本地存储，UTC 时间持久化，界面按本地时间显示。

### 3.2 后续版本

- 回收站和撤销删除
- “今天提醒”“全部未完成”等视图
- 延后提醒、通知动作按钮和原生 WinRT Toast
- 周期性提醒
- JSON 导入导出和自动备份
- 系统深色模式及无障碍选项
- 数字角标、搜索和标签

### 3.3 明确不包含

第一版不包含账号、云同步、协作、附件、Markdown、AI 整理及移动端。

## 4. 技术选择

| 领域 | 选择 | 原因 |
|---|---|---|
| 语言 | C++20 | 与现有 Qt/MinGW 环境匹配 |
| UI | Qt 6 Widgets | 桌面窗口、托盘、焦点与鼠标处理成熟 |
| 构建 | CMake + Ninja | Qt Creator 原生支持、便于自动化 |
| 数据库 | Qt SQL + SQLite | 无服务器、随应用部署、事务可靠 |
| 设置 | QSettings | 适合窗口位置和用户偏好 |
| 提醒 | QTimer + QSystemTrayIcon | 无额外 Windows SDK 依赖，满足 MVP |
| 单实例 | QLocalServer/QLocalSocket | 跨平台且实现简单 |
| 发布 | windeployqt | 自动收集 Qt DLL 和插件 |

## 5. 架构

```text
MemoAssistant
├── MemoApplication        应用生命周期、窗口协调、托盘菜单
├── UI
│   ├── FloatingBall       拖动、吸附、点击与绘制
│   ├── MemoPanel          今日列表和自动收起信号
│   ├── MemoItemWidget     单条记录操作
│   ├── MemoEditorDialog   创建与编辑
│   └── IconFactory        无外部素材的矢量图标绘制
├── Services
│   ├── ReminderService    周期扫描和通知
│   ├── SettingsService    配置及 Windows 启动项
│   └── SingleInstanceGuard 单实例通信
├── Data
│   ├── DatabaseManager    连接、PRAGMA 和建表
│   └── MemoRepository     SQL 和领域对象映射
└── Models
    └── Memo               记录模型
```

原则：UI 不直接书写 SQL；Repository 不依赖窗口；所有存储时间使用 UTC；本地日期边界转换为 UTC 后查询。

## 6. 数据模型

`memos` 表：

| 字段 | 类型 | 规则 |
|---|---|---|
| id | INTEGER | 自增主键 |
| title | TEXT | 必填，去除首尾空格，最大 200 字符（界面限制） |
| content | TEXT | 默认空字符串 |
| created_at | TEXT | UTC ISO 8601，必填 |
| updated_at | TEXT | UTC ISO 8601，必填 |
| reminder_at | TEXT | 可空，UTC ISO 8601 |
| completed_at | TEXT | 可空，UTC ISO 8601 |
| completed | INTEGER | 0/1 |
| reminder_sent | INTEGER | 0/1 |

启用：

- `foreign_keys=ON`
- `journal_mode=WAL`
- `busy_timeout=5000`
- `user_version=1`

索引覆盖创建日期查询和到期提醒查询。

## 7. 关键交互

### 7.1 悬浮球

- `Qt::Tool | Qt::FramelessWindowHint | Qt::WindowStaysOnTopHint`
- `WA_TranslucentBackground` 提供圆形透明窗口。
- 鼠标移动超过系统 `startDragDistance` 才视为拖动，否则释放时视为单击。
- 使用 `QScreen::availableGeometry()`，避免遮挡任务栏。
- 每次拖动后保存逻辑位置；Qt 的高 DPI 坐标系统负责 DIP 缩放。

### 7.2 面板

- 展开方向根据悬浮球所在位置和可用工作区动态决定。
- 显示前重新读取数据库，确保提醒或其他入口修改后同步。
- 鼠标离开后启动单次收起计时器；到期时再次检查鼠标是否位于悬浮球/面板内，并确认没有模态对话框。
- `Esc` 和关闭按钮立即隐藏面板，但不退出进程。

### 7.3 提醒

- 启动时立即扫描，然后每 30 秒扫描。
- 查询条件：提醒时间非空、已到期、未发送、未完成。
- 一条到期时展示标题，多条到期时合并通知。
- 成功请求系统通知后将 `reminder_sent` 置 1，避免重复。
- 修改提醒时间会重置发送状态。

限制：`QSystemTrayIcon` 无法可靠提供“完成/延后”动作按钮；增强版改用 Windows App SDK/WinRT Toast。

## 8. 数据和隐私

- 默认数据位置：`QStandardPaths::AppLocalDataLocation/memo.db`。
- 不联网、不收集遥测、不上传内容。
- 数据库采用事务建表和 WAL 日志。
- 不要求管理员权限。
- 开机启动仅写当前用户 `HKCU` Run 项。

## 9. Windows 与 Qt 边界情况

1. **多显示器拔插**：启动时检查保存位置，落在不可用区域则回到主屏右侧。
2. **不同 DPI**：全部使用 Qt 逻辑像素，不混用 Win32 物理像素。
3. **任务栏位置变化**：使用 `availableGeometry` 而不是完整屏幕矩形。
4. **电脑休眠**：恢复后最多 30 秒内补查；系统可能合并通知。
5. **系统时间/时区改变**：记录使用 UTC；“今天”每次刷新按当前本地时区换算边界。
6. **通知被禁用**：应用仍会记录通知已请求；后续可增加权限诊断页。
7. **资源管理器重启**：Qt 通常会恢复托盘图标；发布前须实机验证。
8. **重复启动**：第二实例通过本地套接字通知第一实例显示面板，然后退出。
9. **数据库异常**：启动失败时显示明确错误，避免静默丢数据。
10. **全屏场景**：第一版保持置顶；后续提供“全屏时隐藏”选项。

## 11. 构建与发布

1. 使用 Qt Creator 的 `Desktop Qt 6.11.1 MinGW 64-bit` Kit 配置 CMake。
2. Debug 构建后运行 `ctest --output-on-failure`。
3. Release 构建。
4. 运行 `scripts/package.ps1` 从干净目录部署运行库、许可证材料并生成 SHA-256 清单。
5. 检查脚本输出仅包含应用需要的 Qt 插件和 `qsqlite` 驱动。
6. 在没有 Qt 环境变量的 Windows 11 测试机验证。
7. 使用 `installer/MemoAssistant.iss` 和 Inno Setup 6 制作安装程序。
8. 附带 Qt/LGPL 及第三方许可文本；开源 Qt 应动态链接。

## 12. 完成定义

当程序可从 Qt Creator 和命令行干净构建，自动测试全部通过，核心手工验收项完成，且 `windeployqt` 生成的目录能在干净 Windows 11 用户环境运行时，第一版视为完成。
