检查项：

- [ ] 悬浮球可点击、拖动并吸附左右边缘。
- [ ] 重启后恢复位置。
- [ ] 多显示器切换、拔插后悬浮球仍在可见区域。
- [ ] 默认显示本地日期当天创建的记录。
- [ ] 日期栏可查看前一天、后一天，并可一键回到今天；不能导航到未来。
- [ ] 历史日期标题、空状态以及新增后返回今天的行为正确。
- [ ] 鼠标离开约 700ms 后收起。
- [ ] 编辑期间不会因鼠标离开收起。
- [ ] 中文标题和正文正确保存。
- [ ] 创建、编辑、完成、重新打开和删除均即时刷新。
- [ ] 到期提醒在 30 秒内显示，且托盘可用时不强制弹出模态窗口。
- [ ] 托盘不可用时显示应用内提醒作为回退。
- [ ] 重启后补查未发送的过期提醒。
- [ ] 托盘菜单和悬浮球右键菜单可用。
- [ ] 第二次启动只激活第一实例。
- [ ] 开机启动开关正确写入和移除当前用户启动项。
- [ ] 125%、150%、200% 缩放下布局可用。
- [ ] 退出后进程完全结束。
